# 文本类游戏数据（TXT/INI/CSV）格式笔记

> 实现依据：通用文本语义；合成样本 round-trip 测试
> （tests/test_gamefiles.py）。

大量引擎把文本放在纯文本文件里：Tyrano Builder 的 `.ks` 场景、
Godot 的 CSV 翻译表、无数自研引擎的 `lang/*.txt`、`config.ini`。
本适配器按扩展名分三种模式，全部**保守提取**。

## 模式分派

| 扩展名 | 模式 |
|---|---|
| `.txt` `.text` `.ks` `.sc` | TXT 行模式 |
| `.ini` `.cfg` `.conf` `.properties` `.lang` | INI 键值模式 |
| `.csv` | CSV 表格模式 |

编码：BOM（UTF-8/UTF-16）→ UTF-8 → GBK 顺序探测，回写用同一编码；
译文无法编码时报错中止（绝不静默替换）。

## TXT 行模式

只提取"普通行"：含字母、不含 `=<>{}[]|\~^$`` ` 等**代码特征字符**、
不以 `;` `#` `@` `*` `[` `/` 开头、非 URL/文件名/标识符。
KS 标签行 `[bg storage="room.jpg"]`、赋值行、注释行天然被排除。
按行号定位回写；译文含代码特征字符 → 拒绝写入（防脚本注入）。

## INI 键值模式

只提取 `key = value` 的**值**（节名/键名/注释不动）；路径、扩展名
结尾、布尔、数字值跳过。`=` 前后的空白逐字符保留。

## CSV 表格模式

- 自研 RFC4180 近似解析器：记录每格的**引号风格**，回写逐格还原
  （`a, "b", c` 回写后引号位置不变）
- 第 0 列视为键列不提取；首行若全是 2–3 字母语言码（`en`,`zh-CN`…）
  识别为表头跳过
- 含分隔符/引号/换行的译文自动加引号

## 回写安全

三种模式都是整文件原子重写；TXT/INI 按行号定位，**行集合必须与
提取时一致**（文件被其他工具增删过行 → 明确报错）；CSV 按行列
定位，结构变化同样拒绝。
